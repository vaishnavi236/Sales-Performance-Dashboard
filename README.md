# Sales-Performance-Dashboard
📊 Sales Performance Dashboard – Power BI Project I recently built an interactive Sales Performance Dashboard in Power BI focused on turning raw sales data into actionable insights.
Key highlights:
 • KPI tracking for Sales, Profit, Cost & Quantity
* Region and Product level analysis
* Drill Down & Drill Up hierarchy navigation
* Drill Through detail pages
* Row Level Security (RLS) for controlled data access
* Interactive slicers and dynamic visuals
This project helped me strengthen my skills in data modeling, DAX, and dashboard design best practices.
